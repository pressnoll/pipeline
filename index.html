Provenance

No production database is attached. Every reading on this page is generated by the hydraulic + KNN simulator in js/telemetry.js, which reproduces the signatures described in the project brief: inflow rise, outflow deficit, downstream pressure sag, jet-induced vibration decaying with distance, and joint moisture. Replace that module with the Firebase/ThingSpeak reader when the schema lands — the render layer holds no domain logic and consumes the same frame shape, documented in README.md.

Model card

KNN, k=5, 5 engineered features over a 10 s window, 4 agreeing windows before an alert is raised. 4,820 labelled samples — 3,600 EPANET scenarios, 980 lab rig, 240 field. Hold-out accuracy 96.4 %, macro-F1 0.951. Quantised to 41 KB, resident in ESP32 flash; inference is local, so alerting survives an uplink outage.

Assumptions

Bulk tariff ₦285 / m³ for loss costing. Hazen-Williams C = 110 for headloss. Localisation uncertainty is the flow-balance residual propagated through the pressure gradient, reported at ±1σ. Moisture confirmation only applies within 90 m of an instrumented joint.
