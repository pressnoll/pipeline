Alerts and events

How to read this view

The three nodes compare water entering and leaving the pipeline. Changes in flow, pressure, and vibration help identify the area that needs attention.

How alerts work

The classifier compares pressure, flow, vibration, and moisture. It waits for four agreeing readings before confirming a leak, so a brief disturbance does not become an alert.

About the estimates

Loss cost uses ₦285 per cubic metre. Leak distance is an estimate with a margin of error; moisture only helps when a joint sensor is near the leak.
